# 370-Current-Emerging-Trends-in-CS-

For this project, I worked with a reinforcement learning environment where an agent had to learn how to find a treasure within a maze. The starter code provided the game environment, maze structure, and much of the framework needed to run the program and my responsibility was to complete the Deep Q-Learning algorithm so the agent could learn from its experiences and improve over time. I implemented the parts of the code that handled the agent's decision-making process, experience replay, and training logic. Through repeated training sessions, the agent learned the best path to reach the treasure while avoiding unnecessary moves.

This course helped me better understand how artificial intelligence fits into the larger field of computer science. Before this class, I knew that AI was becoming increasingly important, but I did not fully understand how machine learning systems are trained to make decisions. Through hands-on experience with reinforcement learning, I learned how algorithms can learn from data and experience instead of being explicitly programmed for every possible situation. These concepts apply to many real-world technologies, including robotics, autonomous vehicles, recommendation systems, and other intelligent applications.

Computer scientists solve problems using technology. They design, develop, test, and improve software and systems that help people complete tasks more efficiently. The work involved matters because technology affects nearly every part of our daily lives, from communication and healthcare to education and business. As technology continues to evolve, computer scientists play an important role in creating innovative solutions that can make processes easier, faster, and more reliable.

When approaching a problem as a computer scientist, I try to understand the requirements and determine the desired outcome. Then I break the problem into smaller pieces that are easier to solve and test. Throughout this project, I followed an iterative process of developing a solution, testing the results, identifying issues, and making improvements. This approach helped me understand how important patience, problem-solving, and continuous improvement are when developing software and AI systems.

My ethical responsibility to both the end user and the organization is to create systems that are reliable, secure, and fair. Users should be able to trust that technology functions as intended and that their information is protected. Organizations also have a responsibility to use technology ethically, especially when developing artificial intelligence solutions that can influence decisions and outcomes. As a computer scientist, I must consider issues such as bias, privacy, transparency, and accountability so that the systems I develop have a positive impact on users and society.
